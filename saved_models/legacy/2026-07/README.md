# Legacy-Artefakte der früheren Juli-Auswertung

Die beiden Grafiken in `forecaster/` zeigen einen früheren Testausschnitt aus
Juli 2026. Der aktuelle Projektstand verwendet ausschließlich Juni 2026 als
Testabschnitt und erzeugt diese zwei historischen Diagnosegrafiken nicht mehr.
Sie sind nur zur Nachvollziehbarkeit archiviert und dürfen nicht als aktuelle
Ergebnisse verwendet werden.
